# 🚌 Bus Ticketing System

A simple and responsive **Bus Ticketing** web application for booking bus tickets online. This project demonstrates modern web development using **HTML**, **CSS**, and **JavaScript**, and is deployed using **GitHub Pages**.

🔗 **Live Demo**: [https://nurmohammadrahul.github.io/bus_ticketing/](https://nurmohammadrahul.github.io/bus_ticketing/)

---

## 🚀 Features

- Select bus seats with visual seat map
- Real-time seat availability updates
- Ticket summary with total price
- Responsive design for mobile and desktop
- Clean and interactive UI/UX

## 🛠️ Technologies Used

- CSS3
